## 3. 共通の仕様

### 3.1 レイアウト
画面の幅によって、3 つの形を切り替える。どの幅でも横スクロールは出さない(NF-A11Y-01)。

| 幅 | 形 |
|---|---|
| 1024px 以上(PC) | 左にメニュー(文字とアイコン)、中央に本体(幅 640px まで)、右に検索欄とトレンドの上位 5 件 |
| 640〜1023px(タブレット) | 左にメニュー(アイコンだけ。マウスを乗せる・キーボードで選ぶと名前を表示)、中央に本体。右の列は出さない |
| 639px 以下(スマートフォン) | 上に画面の名前のバー、下にメニュー(5 項目)、右下に「投稿する」ボタン。本体は画面の幅いっぱい |

### 3.2 メニュー

| 項目 | 移動先 | 補足 |
|---|---|---|
| ホーム | S-05 | |
| 検索 | S-10 | |
| 通知 | S-09 | 未読があれば件数のバッジを出す(例: 「通知 3件の未読」)。99 件を超えたら「99+」 |
| トレンド | S-11 | スマートフォンでは出さない(検索画面から移れる) |
| ブックマーク | S-13 | スマートフォンでは出さない(プロフィールのメニューから移れる) |
| プロフィール | S-07(自分) | |
| 設定 | S-14 | スマートフォンでは出さない(プロフィールのメニューから移れる) |
| 管理者画面 | S-15 | 管理者にだけ出す |
| 投稿する | D-01 を開く | PC・タブレットではメニューの下、スマートフォンでは右下 |

- 今いる画面のメニューは、太字と左側の線で示し、読み上げソフトには「現在のページ」と伝える(色だけで示さない)
- 未読のバッジは、通知が届くとその場で増える(F-NOTIF-03)。数字の変化は読み上げソフトにも伝える

### 3.3 お知らせ欄
taskboard と同じく、操作の結果を文字で知らせる。

- 画面の上部(スマートフォンでは下のメニューの上)に表示し、5 秒で消える。エラーのときは消さず、「閉じる」ボタンで消す
- 成功: 「投稿しました」など。エラー: 赤い枠と、先頭に「エラー:」の文字(色だけに頼らない)
- 読み上げソフトにも、表示した文を読ませる

### 3.4 共通の部品

#### 投稿カード(PostCard)
タイムライン・プロフィール・検索などの一覧で、投稿 1 件を表示する部品。

| 部分 | 内容 |
|---|---|
| アイコン | 投稿者のアイコン(未設定なら標準のアイコン)。クリックでプロフィールへ |
| 名前の行 | 表示名(太字)・`@ユーザーID`・投稿日時。表示名とユーザーIDのクリックでプロフィールへ |
| 投稿日時 | 1 分未満は「たった今」、1 時間未満は「○分前」、24 時間未満は「○時間前」、今年は「10月25日」、それより前は「2025年10月25日」(F-POST-09)。マウスを乗せると「2026年11月1日 12:15」の形で表示 |
| 編集済み | `editedAt` があれば日時の後ろに「(編集済み)」 |
| 返信先 | 返信なら本文の上に「@hanako さんへの返信」。返信先が見られないときは「削除された投稿への返信」 |
| 本文 | 改行を保って表示。`#タグ`・`@ユーザーID`・URL はリンクにする(F-POST-04)。URL は新しいタブで開き、そのことを「(新しいタブで開きます)」と読み上げソフトに伝える |
| 画像 | 1 枚は大きく 1 つ、2 枚以上は 2 列に並べる。5 枚以上のときは 4 枚目に「+○枚」を重ねて表示。クリックで D-05 を開く。代替テキストを `alt` に入れる |
| 操作の行 | 「返信 ○」「いいね ○」「ブックマーク」の 3 つのボタン(下の表) |
| その他のメニュー | 「…」ボタン。自分の投稿なら「編集」「削除」、他人の投稿なら「@○○さんをミュート」「@○○さんをブロック」 |

操作の行のボタン:

| ボタン | 押していない状態 | 押した状態 | 押したとき |
|---|---|---|---|
| 返信 | 吹き出しの形と「返信 2」 | — | 投稿詳細(S-06)を開き、返信の入力欄にキーボードの位置を移す |
| いいね | 白抜きのハートと「いいね 5」 | 塗りつぶしたハートと「いいね済み 6」 | すぐに表示を切り替え、裏でサーバーに保存する。失敗したら元に戻し、お知らせ欄に「エラー: いいねできませんでした」(F-REACT-01〜03) |
| ブックマーク | 白抜きのしおりと「ブックマーク」 | 塗りつぶしたしおりと「ブックマーク済み」 | いいねと同じ動き(F-REACT-04) |

- 押した状態は、形と文字の両方で示し、読み上げソフトには「押されている」状態として伝える
- カードの何もないところをクリックすると、投稿詳細(S-06)を開く。キーボードでは、カードの中のリンク・ボタンを順に選べる

#### ユーザーの行(UserRow)
フォロー一覧・検索結果などで、ユーザー 1 人を表示する部品。アイコン・表示名・`@ユーザーID`・自己紹介(2 行まで)・「フォローされています」(相手が自分をフォローしているとき)・フォローボタン。

フォローボタン: 未フォローは「フォローする」、フォロー中は「フォロー中」。フォロー中のボタンにマウスを乗せる・キーボードで選ぶと「フォローを解除」に変わる。自分の行には出さない。

#### 一覧の状態の表示
すべての一覧で、次の表示を使う。

| 状態 | 表示 |
|---|---|
| 最初の読み込み中 | 投稿カードの形の灰色の枠を 3 つと「読み込み中」(読み上げソフト向け) |
| 続きの読み込み中 | 一覧の下に「読み込み中…」 |
| 0 件 | 画面ごとの文(各画面の欄に書く) |
| 最後まで表示した | 一覧の下に「これ以上はありません」 |
| 読み込みの失敗 | 「エラー: 読み込めませんでした」と「もう一度読み込む」ボタン |

続きの読み込みは、一覧の下端が見えたら自動で行う。キーボードの利用者のために、下端に「さらに読み込む」ボタンも置く(F-TL-03)。

### 3.5 ダイアログの共通ルール
taskboard と同じく、ブラウザ標準の `dialog` を使う。
- Esc キーか「閉じる」「やめる」で閉じる。閉じると、開いたときに押したボタンにキーボードの位置を戻す
- 開いている間は、ダイアログの外を操作できない
- 取り消せない操作の確認では、最初は「やめる」を選んだ状態にする
- 入力途中の内容があるのに閉じようとしたら「入力した内容は消えます。閉じますか?」と確認する

### 3.6 入力欄の共通ルール
- すべての入力欄に、見える名前(ラベル)を付ける。必須の欄は名前の後ろに「(必須)」と書く
- 入力ミスは、欄の下に赤い文字と「!」の印で表示し、欄と結びつけて読み上げソフトにも伝える。送信ボタンを押したときにミスがあれば、最初のミスの欄にキーボードの位置を移す
- 文字数に上限がある欄は、右下に「残り ○ 文字」を表示する。残り 20 文字を切ったら太字にし、超えたら「○ 文字オーバー」と表示して送信ボタンを押せなくする
- 送信中はボタンを押せなくし、「送信中…」と表示する

### 3.7 見やすさの共通ルール(NF-A11Y)
- 文字の大きさは標準 18px(taskboard と同じく大きめ)。行の高さは 1.6
- 文字と背景の明るさの差は、通常の文字で 4.5:1 以上、大きい文字とアイコンで 3:1 以上にする
- ライトモード・ダークモードは、最初は端末の設定に合わせる。設定画面(S-14)で「端末に合わせる / ライト / ダーク」を選べ、選んだものはブラウザに保存する(NF-A11Y-05)
- キーボードで選んでいる場所は、太い枠線ではっきり示す
- 状態は色だけで示さない(いいね済み・フォロー中・未読・エラー・非表示などは、文字や形でも示す)(NF-A11Y-06)
- 各画面の先頭に、本文へ飛ぶ「本文へ移動」リンクを置く(キーボードで最初に選んだときだけ見える)
- 画面が切り替わったら、画面の見出しにキーボードの位置を移し、ブラウザのタブの題名を「画面名 / SNS」に変える

## 4. 画面ごとの仕様

### S-01 ログイン
- **目的**: 登録済みのユーザーがログインする
- **API**: `POST /api/auth/login`、`GET /oauth2/authorization/google`、`POST /api/auth/verify-email/resend`

表示項目:

| 項目 | 内容 |
|---|---|
| 見出し | 「ログイン」 |
| Google でログイン | Google のマークと「Google でログイン」ボタン |
| 区切り | 「または」 |
| メールアドレス | 入力欄(必須) |
| パスワード | 入力欄(必須)。「パスワードを表示」ボタンで文字を見せる・隠すを切り替える |
| ログインボタン | 「ログイン」 |
| リンク | 「パスワードを忘れた方」(S-03)、「アカウントを作成する」(S-02) |

操作とメッセージ:

| 場面 | 画面の動き・メッセージ |
|---|---|
| ログインに成功 | 初期設定前なら S-04、そうでなければ、ログイン前に開こうとしていた画面(なければ S-05)へ |
| メールアドレスかパスワードが違う | フォームの上に「エラー: メールアドレスまたはパスワードが違います」 |
| メールアドレスの確認前 | 「エラー: メールアドレスの確認が済んでいません」と「確認メールを送り直す」ボタン。押すと「確認メールを送りました」 |
| 利用停止中 | 「エラー: このアカウントは利用停止中です」 |
| ロック中 | 「エラー: ログインの失敗が続いたため、15分間ログインできません」 |
| Google ログインから戻って利用停止中 | URL の `?error=suspended` を見て「エラー: このアカウントは利用停止中です」 |

### S-02 新規登録
- **目的**: 新しいアカウントを作る
- **API**: `POST /api/auth/signup`、`GET /oauth2/authorization/google`

| 項目 | 内容 |
|---|---|
| 見出し | 「アカウントを作成」 |
| Google で登録 | 「Google で登録」ボタン |
| メールアドレス | 入力欄(必須) |
| パスワード | 入力欄(必須)。下に「8文字以上72文字以内」と案内。「パスワードを表示」ボタン |
| 登録ボタン | 「登録する」 |
| リンク | 「アカウントをお持ちの方はログイン」(S-01) |

| 場面 | 画面の動き・メッセージ |
|---|---|
| 登録に成功 | フォームを消して「確認メールを送りました。メールのリンクを開いて登録を完了してください(リンクの有効期限は24時間です)」と、「確認メールを送り直す」ボタンを表示 |
| 登録済みのメールアドレス | メールアドレスの欄の下に「このメールアドレスは登録済みです」と、ログイン画面へのリンク |
| 入力ミス | 各欄の下に、機能定義書 3.1 のメッセージ |

### S-02a メールアドレスの確認
- **目的**: メールのリンクから開き、登録を完了する
- **API**: `POST /api/auth/verify-email`
- 開くとすぐに確認を行い、その間は「確認しています…」と表示する

| 場面 | 画面の動き・メッセージ |
|---|---|
| 成功 | ログイン状態になり、S-04 へ移る |
| 期限切れ・使用済み | 「エラー: このリンクは期限切れか、すでに使われています」と、「ログイン画面へ」のリンク(ログイン画面から確認メールを送り直せる) |

### S-03 パスワード再設定
- **目的**: パスワードを忘れたときに、新しいパスワードを設定する
- **API**: `POST /api/auth/password-reset`、`POST /api/auth/password-reset/confirm`
- URL に `token` がないときは「メールの送信」、あるときは「新しいパスワードの設定」を表示する

| 状態 | 表示項目 | 操作の結果 |
|---|---|---|
| メールの送信 | 説明文「登録したメールアドレスを入力してください。パスワードを再設定するためのリンクを送ります」、メールアドレス(必須)、「送信する」ボタン | 「入力したメールアドレスが登録されていれば、再設定のメールを送りました(リンクの有効期限は1時間です)」(登録の有無で文を変えない) |
| 新しいパスワードの設定 | 新しいパスワード(必須)、確認のためもう一度(必須)、「設定する」ボタン | 成功: S-01 へ移り「パスワードを変更しました。新しいパスワードでログインしてください」。2 つの欄が違う: 「パスワードが一致しません」。期限切れ: S-02a と同じエラー |

### S-04 初期設定
- **目的**: 初めてログインしたときに、ユーザーIDと表示名を決める
- **API**: `POST /api/me/onboarding`、`GET /api/handles/{handle}/availability`
- 初期設定が済むまで、他の画面には移れない(メニューは出さない。「ログアウト」だけ出す)

| 項目 | 内容 |
|---|---|
| 見出し | 「プロフィールを設定しましょう」 |
| ユーザーID | 入力欄(必須)。前に「@」を固定で表示。下に「半角英数字と_の3〜15文字。あとから変更できません」。入力を止めて 0.5 秒たったら使えるかを確かめ、「使えます」(チェックの印)か「このユーザーIDは使われています」(×の印)を表示 |
| 表示名 | 入力欄(必須)。残り文字数を表示(50 文字) |
| ボタン | 「はじめる」 |

成功したら S-05 へ移り、お知らせ欄に「ようこそ!」と表示する。

### S-05 ホーム
- **目的**: タイムラインを見る。投稿する
- **API**: `GET /api/timeline`、`POST /api/posts`、SSE `/api/stream`

表示項目(上から):

| 項目 | 内容 |
|---|---|
| 見出し | 「ホーム」 |
| タブ | 「すべて」「フォロー中」(F-TL-01, F-TL-02)。選んだタブは URL(`/?tab=following`)とブラウザに覚えておき、次に開いたときも同じタブにする |
| 投稿欄 | PC・タブレットだけ表示(スマートフォンは右下の「投稿する」ボタンから D-01)。中身は D-01 の入力部分と同じ |
| 新着のお知らせ | 下にスクロールしている間に新着が届いたとき、画面の上部に「↑ 新しい投稿 ○件」ボタン(下記) |
| タイムライン | 投稿カードの一覧(3.4) |

新着の取り込み(F-TL-04, F-TL-05):
- 一覧の一番上を見ているときは、届いた投稿をそのまま先頭に足す
- 下にスクロールしているときも先頭に足すが、足した分だけスクロールの位置を下げ、見ている投稿が動かないようにする。そのうえで「↑ 新しい投稿 ○件」ボタンを出す。押すと一番上に戻り、ボタンは消える
- 足した投稿は、少しの間だけ左側に線を付けて、新しいことを示す(動きを減らす設定の端末では、動きを付けない)
- 新着が届いたことは読み上げソフトには知らせない(読み上げが何度も割り込まないように)。「新しい投稿 ○件」のボタンは読み上げの対象にする
- 削除・非表示にされた投稿(SSE の `post-deleted`)は、一覧から消す

| 0 件のときの表示 | 内容 |
|---|---|

### S-06 投稿詳細

### S-09 通知

- **API**: `GET /api/notifications`、`POST /api/notifications/read`、SSE `/api/stream`

| 項目 | 内容 |
|---|---|
| 見出し | 「通知」 |
| 一覧 | 通知 1 件ごとに、種類のアイコンと文・相手のアイコン・日時・対象の投稿の先頭 40 文字 |
| 未読の印 | 未読の通知は、背景を薄く色付けし、さらに文の前に「未読」と表示する(色だけに頼らない) |

通知の文:

| 種類 | 文 |
|---|---|
| いいね | 「○○さんがあなたの投稿にいいねしました」 |

- 0 件: 「『○○』に一致する結果はありません」

## 5. ダイアログ

### D-01 投稿の作成
ホーム(S-05)の投稿欄、投稿詳細(S-06)の返信欄、スマートフォンの「投稿する」ボタンから使う。返信のときは上に「@○○さんへの返信」と表示する。

| 項目 | 内容 |
|---|---|
| 本文 | 複数行の入力欄。「いまどうしてる?」(返信では「返信をポスト」)。入力に合わせて高さが伸びる。残り文字数を表示(1000 文字)(F-POST-01) |
| 画像を追加 | 「画像を追加」ボタン(ファイルを選ぶ。複数選べる)。画像を入力欄に貼り付けても追加できる。最大 10 枚(F-POST-02) |
| 画像のプレビュー | 選んだ画像を小さく並べる。それぞれに「取り消す」(×)ボタンと「説明を追加」ボタン。説明を入れた画像には「説明あり」と表示 |
| 画像の説明 | 「説明を追加」を押すと、その画像の下に入力欄が開く(「画像の内容を、目の不自由な方にも伝わるように書いてください」)(F-POST-03) |
| 投稿ボタン | 「投稿する」。本文も画像もないとき、文字数を超えたときは押せない |

| 場面 | 画面の動き・メッセージ |
|---|---|
| 画像を選んだ | 送る前にブラウザで縮小する(長辺 2048px 程度)。縮小中は「画像を準備しています…」 |
| 11 枚目を選んだ | 「画像は10枚までです」(10 枚を超えた分は追加しない) |
| 形式が違う | 「JPEG・PNG・WebP・GIF の画像を選んでください」 |
| 縮小しても 5MB を超える | 「5MB以下の画像を選んでください」 |
| 投稿に成功 | 入力欄を空にし、タイムライン(または返信の一覧)に足して「投稿しました」。スマートフォンのダイアログは閉じる |
| 投稿に失敗 | 入力内容は消さずに残し、「エラー: 投稿できませんでした。もう一度お試しください」 |
| Ctrl + Enter | 「投稿する」と同じ |

### D-02 投稿の編集
- 本文の入力欄(今の本文が入った状態)と、「保存する」「やめる」ボタン。画像は表示するだけで、変えられない(「画像は変更できません」の説明)(F-POST-05)
- 保存したら、カードの本文を変え、「(編集済み)」を付けて「投稿を編集しました」

### D-03 投稿の削除の確認
- 「この投稿を削除しますか?削除すると元に戻せません」と、「削除する」「やめる」ボタン。最初は「やめる」を選んだ状態(F-POST-06)
- 削除したら、一覧から消して「投稿を削除しました」

### D-04 ブロックの確認
- 「@○○さんをブロックしますか?」と、次の説明。「お互いの投稿が見えなくなります」「お互いのフォローが解除されます」「相手はあなたをフォロー・返信・いいねできなくなります」
- 「ブロックする」「やめる」ボタン。最初は「やめる」を選んだ状態(F-BLOCK-02)

### D-05 画像の拡大表示
- 画面いっぱいに画像を表示し、下に代替テキストを表示する
- 「←」「→」ボタン(キーボードの左右の矢印キーでも)で、同じ投稿の画像を切り替える。「3 / 5」のように何枚目かを表示
- 「閉じる」ボタン、Esc キー、画像の外のクリックで閉じる

### D-06 管理者の操作の確認
- 投稿の非表示: 「この投稿を非表示にしますか?投稿者以外には表示されなくなります」
- ユーザーの利用停止: 「@○○さんを利用停止にしますか?すぐにログアウトされ、投稿も表示されなくなります」
- 「実行する」「やめる」ボタン。最初は「やめる」を選んだ状態(F-ADMIN-04, F-ADMIN-05)
